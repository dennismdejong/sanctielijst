# Audit-log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Elke zoekopdracht en PDF/CSV-export loggen — herleidbaar op basis van IP-adres (timestamp, query, resultaten, bronnen) — met een beveiligde admin-weergave. Geen login vereist.

**Architecture:** Een `app/audit.py`-module schrijft append-only events naar `data/audit.sqlite` (los van `search.sqlite`, die wordt herbouwd). De zoek- en export-routes loggen via een kleine helper. Het client-IP komt uit `request.client.host` (achter Traefik via `X-Forwarded-For`, uvicorn `--proxy-headers`). Admin-weergave via `GET /api/audit` beveiligd met een Bearer-token uit env `AUDIT_ADMIN_TOKEN`.

**Tech Stack:** Python 3.11, stdlib `sqlite3`, bestaande FastAPI; geen nieuwe dependencies.

## Global Constraints

- Audit-data apart van de zoekindex: `data/audit.sqlite` (env `AUDIT_DB`), tabel `audit_log`.
- Elk event: `timestamp` (UTC ISO), `ip`, `user_agent`, `method`, `path`, `query` (JSON), `result_count`, `sources` (JSON: eu/pep/opensanctions), `threshold`.
- Loggen bij: `GET /api/search` en `GET /api/search/export` (alle formats), inclusief 422/leeg-resultaat (met result_count 0).
- `GET /api/audit?limit=&offset=` retourneert events gesorteerd op `ts` desc; vereist header `Authorization: Bearer <AUDIT_ADMIN_TOKEN>`; zonder token of bij onjuiste token → 401. Als `AUDIT_ADMIN_TOKEN` niet gezet is → endpoint uitgeschakeld (404).
- Loggen mag nooit de zoekopdracht laten falen: audit-fouten worden geslikt + `logger.warning`.
- UI-taal Nederlands; identifiers Engels. Geen code-commentaar tenzij niet-voor-de-hand liggend.
- STAGE nooit via `git add .`; alleen eigen bestanden. Testsuite: `.venv/bin/python -m pytest -v`.

### Task 1: audit-module

**Files:**
- Create: `app/audit.py`
- Test: `tests/test_audit.py`

**Interfaces:**
- Produces:
  - `default_audit_db() -> Path` — `AUDIT_DB` env of `Path("data") / "audit.sqlite"`.
  - `init_audit_db(db_path: Path) -> None` — maakt schema (idempotent): `CREATE TABLE IF NOT EXISTS audit_log (id INTEGER PRIMARY KEY AUTOINCREMENT, ts TEXT NOT NULL, ip TEXT NOT NULL, user_agent TEXT, method TEXT, path TEXT, query TEXT, result_count INTEGER, sources TEXT, threshold INTEGER)`.
  - `log_event(db_path: Path, *, ip, user_agent, method, path, query: dict, result_count: int, sources: list[str], threshold: int) -> None` — insert; idempotent op ontbrekende DB (maakt aan).
  - `list_events(db_path: Path, limit: int = 100, offset: int = 0) -> list[dict]` — events desc op ts.

**Tests:** init maakt tabel; log_event schrijft + leest terug; ontbrekende DB wordt aangemaakt; list_events sorteert en limiteert.

### Task 2: loggen in de routes + IP

**Files:**
- Modify: `app/main.py`
- Test: `tests/test_main.py`

**Interfaces:**
- Consumes: `app.audit`.
- Produces:
  - In `create_app`: `audit_db = default_audit_db()`; uvicorn draait met `--proxy-headers` (documenteren; in tests `request.client.host` gebruiken).
  - Helper `_log_search(request, query, results, warnings)` binnen `create_app` — bouwt het event (ip = `request.client.host`, user_agent = header, sources uit de resultaten), roept `audit.log_event` in try/except.
  - Aanroep in `search()` en `search_export()` (na het samenstellen van `results`).
  - `GET /api/audit?limit=&offset=` — token-check via `AUDIT_ADMIN_TOKEN`; 401 bij ongeldig; 404 als env leeg.

**Tests:** zoeken logt (event met ip, query, result_count); export logt; audit-endpoint: zonder token 401, met juiste Bearer-token events, lege env → 404; audit-fout breekt de zoekopdracht niet (monkeypatch `log_event` → raise).
